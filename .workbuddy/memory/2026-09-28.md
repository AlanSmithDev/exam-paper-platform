### 关键结论（重要，后续别再重复踩）
- **1600 万道题靠爬虫做不到**：菁优网/学科网组卷都是 JS 骨架页 + AJAX + 登录墙，
  公开可抓中文题库总量仅 5~15 万；商业题库受著作权保护，商用有侵权风险。
  已在 `题库/_meta/README_题库建设方案.md` 给出 4 条现实路径（商业授权 > AI 合成 > UGC > 开源聚合）。
- **数学图形不要存截图**：应存 LaTeX 源码由前端 KaTeX 渲染（省 99% 存储、可检索、排版自适应）。
  本轮 1458 道含公式题已保留 LaTeX。

### 本机环境坑（本次实测新增）
- `raw.githubusercontent.com` 直连超时；**`gh-proxy.com` / `ghproxy.net` 镜像 1.4s 可用**，
  jsdelivr 也能通但慢(10s)。采集器已内置多镜像 fallback。
- GitHub API `git/trees` 需**回退 ref**：CMMLU 默认分支不是 main，`list_repo_files` 要试 main→master。
- 中文路径 fetch 必须 `urllib.parse.quote(path, safe='/')`，否则 404。
- Bash 工具无 coreutils（head/tail/dirname 全无）→ 一律用 Python 驱动；
  长任务(>120s)必须 `run_in_background`，否则前台 SIGTERM。
- Python `%` 与 `+` 同优先级左结合：`A + B + C % (x)` 会把格式化落到 C 上 → 标题要单独先格式化。
- `学科目录.json` 用 utf-8-sig 写的，读取必须 `encoding="utf-8-sig"`，否则 BOM 报错。

### 本轮实测新增的关键事实（供后续直接引用，别再重测）
- **`hf-mirror.com` 可达（0.6s）**，`huggingface.co` 直连 502 → HF 数据集一律走 hf-mirror，
  下载直链格式 `https://hf-mirror.com/datasets/<repo>/resolve/main/<file>`。
- **cn-k12**（`aslawliet/cn-k12`）：369MB，**实测 276,891 条**，100% 有 solution，98.6% 含 LaTeX，
  **但中文比例 0.0%——是英文数学题**，不能计入中文题库。
- **COIG exam**（`BAAI/COIG/exam_instructions.jsonl`）：76MB，**实测 63,536 条，中文 82.9%**，
  字段 `textbox_q_instruction/_context/_question/_answer/_answer_analysis/subject`，
  **题目+答案+解析齐全 → 目前最优质的中文源**，下阶段优先接。
- **pretty-print JSON 流式解析坑**：`buf.find('{"problem"')` 永远匹配不到（`{` 与 key 间有换行）；
  正确做法 `find('"problem"')` → `rfind('{',0,i)` → `JSONDecoder().raw_decode(buf,start)`。
- 修正后的中文题可行性：A类开源(仅中文)12~15万 + B类PDF/OCR 30~80万 + C类公开站 10~50万
  = **中性预期 80~120 万，200 万纯爬虫大概率达不到**（比上一轮估的更准确）。

### 图片方案结论（用户点名问的）
公式不存图（存 LaTeX + 前端 KaTeX）；几何图优先抓 SVG；位图转 WebP(q80, 长边1200)；
